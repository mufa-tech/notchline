Confidentialité

Mis à jour le 2 novembre 2026.

Notchline ne collecte aucune donnée. Rien de ce que vous saisissez ou mesurez ne quitte votre téléphone.

L’appli

Notchline n’a pas de compte, pas de connexion, pas de statistiques, pas de rapport de plantage, pas de pub et aucun pistage. Elle ne demande aucune autorisation. Vos chantiers et vos réglages sont gardés dans un seul fichier, à l’intérieur de l’appli, sur votre téléphone.

La mesure de pente lit le capteur de mouvement du téléphone (l’accéléromètre) tant qu’elle est ouverte, pour mesurer l’angle d’un chevron ou d’un toit. Les lectures restent sur le téléphone et ne sont pas enregistrées ; seule la pente que vous choisissez d’utiliser va dans le chantier.

Les sauvegardes, les fiches chantier et les fiches PDF ne quittent le téléphone que si vous les partagez ou les enregistrez vous-même, par le menu de partage ou le sélecteur de fichiers, à l’endroit de votre choix. Nous ne les recevons jamais.

Achats

Pro s’achète sur l’App Store ou Google Play. Le store gère le paiement ; l’appli apprend seulement que Pro est actif et le garde sur le téléphone.

E-mail

Si vous écrivez à hello@mufatech.com, nous lisons votre message pour y répondre et le gardons dans notre boîte. Nous ne vous inscrivons à aucune liste.

Ce site

Ce site n’a pas de cookies, pas de statistiques et aucun code tiers. Les outils de calcul tournent dans votre navigateur ; rien de ce que vous saisissez n’est envoyé. Le site est hébergé sur GitHub Pages, qui tient des journaux serveur ordinaires.
